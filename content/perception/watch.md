# Watch out

Notes from Phineas's kit on things that are easy to mix up or where the slides need care. Each starts with the deck it belongs to.

- (deck 1) Change blindness vs. inattentional blindness is the classic trap. Both happen because attention is elsewhere. Missed a change → change blindness. Missed a visible object → inattentional blindness.
- (deck 1) Bottom-up = sensation (receptors send information up). Top-down = perception (your knowledge, experience, or context interprets it).
- (deck 1) Both thresholds are measured at 50% of the time. Absolute = can you detect it at all? Difference (JND) = can you tell it changed?
